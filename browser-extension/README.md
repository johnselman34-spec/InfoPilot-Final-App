# InfoPilot Explorer Browser Extension

🐻 **First in Flight with Monetization of Searches!**

This browser extension provides quick access to InfoPilot Explorer from any webpage.

## Features

- 🔍 **Quick Search** - Search directly from the popup
- 🎤 **Voice Search** - Use speech-to-text for hands-free searching
- 📋 **Right-Click Search** - Search selected text or links via context menu
- ⌨️ **Keyboard Shortcut** - Press `Ctrl+Shift+I` (or `Cmd+Shift+I` on Mac) to search selected text
- 🔗 **Quick Links** - Fast access to Search, Marketplace, Chat, and Dashboard

## Installation

### Chrome / Edge / Brave

1. Open your browser and go to:
   - **Chrome**: `chrome://extensions`
   - **Edge**: `edge://extensions`
   - **Brave**: `brave://extensions`

2. Enable **Developer mode** (toggle in the top right corner)

3. Click **"Load unpacked"**

4. Select the `browser-extension` folder from this repository

5. The extension icon should appear in your toolbar!

### Firefox

1. Open Firefox and go to `about:debugging#/runtime/this-firefox`

2. Click **"Load Temporary Add-on..."**

3. Select the `manifest.json` file from the `browser-extension` folder

4. The extension will be loaded temporarily (you'll need to reload it each time Firefox restarts)

**Note**: For permanent Firefox installation, the extension needs to be signed by Mozilla.

## Usage

### Popup Search
1. Click the InfoPilot icon in your toolbar
2. Enter your search query
3. Select your preferred search engine
4. Click "Search & Collate"

### Voice Search
1. Click the microphone icon in the popup
2. Speak your search query
3. The text will be automatically filled in

### Context Menu
1. Select text on any webpage
2. Right-click and choose "Search with InfoPilot"
3. InfoPilot will open with your search

### Keyboard Shortcut
1. Select text on any webpage
2. Press `Ctrl+Shift+I` (Windows/Linux) or `Cmd+Shift+I` (Mac)
3. InfoPilot will open with your search

## Permissions

The extension requires these permissions:
- **contextMenus**: For right-click search functionality
- **storage**: To save your preferences
- **activeTab**: To read selected text on the current page
